# Referências visuais

> **Não publicar.** Estas imagens são de terceiros (Pinterest, moodboards montados a partir de fotos da internet, vídeo de um convite de exemplo). Elas servem só para dar contexto ao Cursor e a quem for desenhar. A pasta está no `.gitignore`, então **não vai para o GitHub** (o repositório é público). Se precisar dela em outro computador, copie à mão.
